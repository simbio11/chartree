# 안티그래비티 구현 지시서 — 진료 프로토콜 뷰 (v0.1)

담당: **안티그래비티(아르곤 = 생성·구현 / 하이드로건 = 판독·검수)** · 감독·검수: 아린
작업 위치: `C:\Users\cmksc\workspace\clin-protocol` — **볼트에는 코드를 넣지 않는다**

## 1. 무엇을 만드는가

볼트의 프로토콜 md를 읽어 **진료 중에 쓰는 화면**을 띄우는 로컬 웹앱.
PWA 하나로 진료실 PC(브라우저 전체화면)와 폰(Z Fold 6 홈화면 설치)에서 같이 쓴다.

| 단계 | 내용 | 완료 기준 |
| :--- | :--- | :--- |
| **M0** | 파서(`build_tree.py`) + `tree.json` 생성 + 빈 화면 뜨기 | `--check` exit 0 · `http://127.0.0.1:8765` 200 · 증상 목록 표시 |
| **M1** | 트리 탐색 + 노드 카드 + 검색 | 증상 선택 → 치료 카드까지 **3클릭·10초** |
| **M2** | PWA 설치 + 오프라인 캐시 | 비행기모드에서도 트리 열림 |
| **M3** | 케이스 기록(로컬) + md 내보내기 | 경로·결과 3필드 저장 → 클립보드로 md 복사 |

## 2. 고정 계약 — `tree.json` (v1)

프론트는 이 형식만 안다. 파서가 이 형식을 만들고, 스키마를 바꾸면 아린 승인 필요.

```json
{
  "generated": "2026-11-18T22:00:00+09:00",
  "증상": {
    "HA": {
      "name": "두통",
      "entry": "HA-L0-01",
      "nodes": {
        "HA-L1-01": {
          "id": "HA-L1-01", "유형": "ask", "제목": "레드플래그 확인",
          "상태": "정본", "신뢰도": "상", "근거": "…", "내숙련도": 0,
          "레드플래그": true,
          "질문": "…", "왜": "…",
          "다음": {"예": ["HA-L1-02"], "아니오": ["HA-L1-03"]},
          "본문": "md 섹션 원문",
          "파일": "두통/10_L1_문진.md#HA-L1-01"
        }
      }
    }
  }
}
```

- 파서 입력: `C:\Simbio\_임상\프로토콜\**\*.md` (읽기 전용)
- 노드 구분: `## HA-L1-01 제목` 형태의 2단계 헤딩 + 헤딩 아래 yaml 코드블록
- `유형`별 필수 필드는 `00_스키마.md` §3을 따른다

## 3. 화면 요구

1. **홈**: 증상 그리드 · 통합 검색(증상명·증상코드·노드ID·키워드) · 최근 사용 3개
2. **트리**: L0~L5 가로 열, 노드 카드. 클릭하면 상세 패널(폰은 하단 시트)
3. **노드 패널**
   - ask: 질문 1개 크게 + `왜 묻는가` 작게 + **예/아니오 버튼** 2개
   - treat: 세트 요약 + **복사 버튼**(자침점·용량·빈도 그대로)
   - teach: **환자에게 보여주기** 버튼 → 큰 글씨(24px+) 교육 화면, 뒤로만 가능
   - 레드플래그 노드: 빨간 테두리 + "전원" 고정 문구
   - 숙련도 0~2인 treat: "⚠️ 지도 필요" 배지
4. **경로 바**: 지나온 노드 칩 목록 + 되돌리기
5. **케이스**: 경로 자동 채움 + NRS 전/후·최종진단·메모 3필드 → 로컬 저장(IndexedDB) → `md 내보내기`(클립보드)

## 4. 기술 제약

- 백엔드: Python 표준 라이브러리 + FastAPI(있으면). `127.0.0.1:8765`만 바인딩
- 프론트: **빌드 도구 없이** 정적 HTML/CSS/JS. 외부 CDN·폰트·트래커 금지
- PWA: `manifest.json` + `sw.js`. 캐시 대상 = app shell + `tree.json`
- **금지**: 볼트 파일 쓰기 · 외부 API 호출 · LLM 호출(M1~M3) · 로그인/계정 · 환자 식별정보 저장 · 텔레메트리

## 7. 운영 규칙

- 배치는 **M0 → 검수 → M1 → 검수** 순서. 아린이 `--check` 통과를 확인한 뒤 다음 배치를 넘긴다.
- 아르곤이 코드를 쓰는 동안 하이드로건은 같은 파일을 건드리지 않는다(판독·리뷰만).
- 코드 리뷰 항목: ① 계약 준수 ② 금지사항 위반 0 ③ 진료 중 3클릭·10초 ④ 오프라인 동작

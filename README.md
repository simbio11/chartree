# clin-protocol — 진료 프로토콜 나무 (CLIN-7)

증상 → 문진 → 검사 → 감별 → 치료 → 티칭 → 결과 → 내 숙련도로 이어지는 **가지치기 진료 프로토콜**을 옵시디언 볼트의 md로 축적하고, 진료 중에 그 트리를 따라가며 쓰는 **로컬 PWA 뷰어**입니다.

- 정본 지식은 볼트(`C:\Simbio\_임상\프로토콜\`)에 있고, **이 저장소는 코드만** 담습니다.
- 진료실 PC는 브라우저 전체화면, 폰(Galaxy Z Fold 6)은 홈화면 설치로 같은 화면을 씁니다.

## 마일스톤

| 단계 | 내용 | 완료 기준 |
| :--- | :--- | :--- |
| M0 | `build_tree.py` + `tree.json` + 증상 목록 화면 | `--check` exit 0 · `http://127.0.0.1:8765` 200 |
| M1 | 트리 탐색 · 노드 카드 · 검색 | 증상 선택 → 치료 카드까지 3클릭·10초 |
| M2 | PWA 설치 · 오프라인 캐시 | 비행기모드에서 트리 열림 |
| M3 | 케이스 기록(로컬) · md 내보내기 | 경로·결과 저장 → 클립보드 복사 |

## 실행

```bash
python build_tree.py --check     # 볼트 md 파싱 + 무결성 검사
python serve.py                  # 127.0.0.1:8765
python verify_app.py             # 200 · tree.json 파싱 · 깨진 참조 0
```
